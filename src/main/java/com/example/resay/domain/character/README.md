# character

대화 분석에서 도출된 캐릭터 정보를 이미지로 생성하기 위한 도메인입니다.

- `entity`: 화자별 이미지 생성 상태와 저장 정보를 관리하는 엔티티
- `model`: 이미지 생성 입력과 결과 모델
- `port`: 외부 이미지 생성 및 파일 저장 구현이 지켜야 하는 인터페이스
- `repository`: 캐릭터 이미지 상태를 저장하고 조회하는 저장소
- `service`: 생성 작업의 시작, 완료, 실패 상태를 관리하는 서비스

분석 결과가 커밋되면 화자별 이미지 생성 작업을 비동기로 시작합니다. 이미지 생성 실패는
완료된 대화 분석 상태에 영향을 주지 않으며, 각 화자의 작업은 서로 독립적으로 처리됩니다.

OpenAI 요청 형식이나 Base64 처리 같은 외부 API 세부사항은 이 패키지에 두지 않습니다.
