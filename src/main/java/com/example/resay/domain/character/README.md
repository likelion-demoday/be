# character

대화 분석에서 도출된 캐릭터 정보를 이미지로 생성하기 위한 도메인입니다.

- `entity`: 화자별 이미지 생성 상태와 저장 정보를 관리하는 엔티티
- `model`: 이미지 생성 입력과 결과 모델
- `port`: 외부 이미지 생성 및 파일 저장 구현이 지켜야 하는 인터페이스
- `repository`: 캐릭터 이미지 상태를 저장하고 조회하는 저장소
- `service`: 생성 작업의 시작, 완료, 실패 상태를 관리하는 서비스

분석 완료만으로 이미지를 자동 생성하지 않습니다. 사용자가
`POST /api/v1/analyses/{recordingId}/character-images`를 호출하면 크레딧 차감과 이미지 작업
예약을 한 트랜잭션에서 처리하고, 커밋 후 화자별 이미지 생성을 비동기로 시작합니다.

동일한 분석의 중복 요청은 새 작업이나 차감을 만들지 않습니다. 이미지 생성에 실패하면
캐릭터 생성 크레딧을 환급하며, 실패한 화자의 작업은 다음 사용자 요청에서 재시도할 수
있습니다. 이미지 생성 실패는 완료된 대화 분석 상태에 영향을 주지 않습니다.

`GET /api/v1/analyses/{recordingId}/character-images`로 화자별 생성 상태를 조회합니다.
완료된 항목의 `contentUrl`은 로그인 토큰을 포함한 요청으로 이미지를 내려받을 때 사용합니다.
저장소의 내부 파일 경로는 API에 노출하지 않으므로 로컬 저장소를 S3로 교체해도 응답 계약은
변하지 않습니다.

OpenAI 요청 형식이나 Base64 처리 같은 외부 API 세부사항은 이 패키지에 두지 않습니다.
